# 평균 너머 돋보기

평균은 같은데 불량은 60%? — 데이터를 숫자 몇 개로 요약하는 기술통계를 손으로 체험하는 앱입니다. 평균이 같은 두 생산 라인(σ 1 g vs 10 g), 평균과 중앙값의 차이, 최빈값, 쏠린 분포에서 최빈·중앙·평균의 순서와 왜도, 범위와 사분위 범위, 분산과 n−1(10만 번 실험), 표준편차와 불량률, 첨도(꼬리의 무게) 100만 개 실험, describe() 요약표까지 담았습니다. 빅데이터 05 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 중심: 두 라인 1,000봉지 히스토그램, 마지막 값을 키우는 평균 vs 중앙값, 퀴즈 ①, 티셔츠 사이즈 최빈값
- ② 쏠림: 모의 연봉 10만 명(오른쪽·대칭·왼쪽 꼬리, 꼬리 길이), 퀴즈 ②, 왜도 표
- ③ 퍼짐: 범위 vs IQR, 편차·편차² 표와 ÷n·÷(n−1), n−1 10만 번 실험, 표준편차 슬라이더와 불량 확률
- ④ 꼬리: 정규분포 vs 꼬리 두꺼운 분포 100만 개, describe() 요약표, 세 줄 정리, 생각해 볼 질문
